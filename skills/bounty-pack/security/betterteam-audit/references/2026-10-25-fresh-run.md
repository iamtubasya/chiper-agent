Signing in at `app.betterteam.com/login` funnels to WorkOS, but the **shared `.betterteam.com` session
cookies are accepted by the legacy API**, so authenticated legacy reads work with the dashboard jar.

Resources that EXIST: `/api/jobs`, `/api/companies`, `/api/users`, `/api/applications`, `/api/notes`,
`/api/subscriptions`. The other 27 of 33 probed resource names → 404 (`job_postings`, `customers`,
`charges`, `invoices`, `webhooks`, `templates`, `interviews`, `offers`, `pipeline`, `stages`, `tags`,

`teams`, `members`, `roles`, `permissions`, `api_keys`, `integrations`, `plans`, `prices`, `coupons`).

  `/api/users/<B uuid>` → 404. JSON:API `filter[]`/`include` are **ignored, not honoured** (still own rows).

  (`trust`,`trial-expiration`), `PATCH /api/subscriptions` (`features`,`expiration`) — with valid

  plan-id, product-id, source, source-details, stripe}` — correctly per-account (A vs B different

  client"); `/healthcheck` → 403 JSON:API (3×); `/account`, `/jobs`, `/jobs/{id}`, `/jobs/new`,

## i.betterteam.com / \*.i.betterteam.com — synthetic measurement beacon
`/i/<key>.png` is a **5-hop 302 chain** ending in a real 8×8 PNG. Every hop echoes the path and appends
a fresh nonce/segment (hop counter 1→5, plus a numeric id and two 12-hex blobs); `?c=` is passed through
to every hop. Basename is strictly `[a-z0-9-]`: `.`/`/`/`?`/`#`/`@`/`:`/`%`/space/`<`/`"` → 404.
Only `.png`/`.gif` match an extension probe; `.html/.js/.json/.svg/.css/.xml` → 404 (no MIME confusion).
Traversal (plain, `%2e%2e`, double-encoded, `%00`) → 404. `POST/PUT/DELETE/OPTIONS/TRACE/PATCH` → 404.
`XFH`/`X-Forwarded-Server`/`X-Host`/`X-Original-URL` inert. Wildcard `<anything>.n.d.i` and `g.d.i` →
404 for arbitrary keys. `ns1.d.i.betterteam.com` (136.79.187.74) refuses recursion + CHAOS, blocks AXFR,
NOTIMP on UPDATE and ANY. **Conclusion: hardened, nothing reportable** — the only oddity is Varnish
caching responses that carry `Cache-Control: no-store` (hygiene, zero impact).
